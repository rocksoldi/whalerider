# Contributing

This repository contains WhaleRider's public guides and research examples. Corrections, clearer explanations, and reproducible documentation issues are welcome.

For a documentation or example issue, include the file or section, what you expected, and the smallest example that shows the problem. For a CLI issue, include `wr --version` and the relevant diagnostic output with keys and personal information removed.

Before opening a pull request:

- Check that product wording matches [whalerider.org](https://www.whalerider.org/) and the [current reference](https://www.whalerider.org/docs).
- Keep the README focused on the research workflow. Put detailed instructions in `docs/`.
- Compile changed trade plans and risk policies locally. Strategy and simulation templates need workspace IDs before compilation.
- Check relative links and images, including both README image themes.
- Identify the source and assumptions of any reported historical results.

For workspace access, billing, private account details, or security concerns, contact [whalerider@rocksoldi.com](mailto:whalerider@rocksoldi.com). Keep credentials out of public issues and pull requests.

The hosted platform's implementation is maintained separately. This repository does not grant an open-source license to the platform or brand assets.
