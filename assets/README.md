# Brand and research assets

[← WhaleRider](../README.md)

- `whalerider-logo.svg`: the website's original brand mark.
- `hero-light.svg` and `hero-dark.svg`: README introduction using the website's product message and theme colors.
- `hero-mobile-light.svg` and `hero-mobile-dark.svg`: a larger type layout for narrow screens.
- `pivot-spring-light.svg` and `pivot-spring-dark.svg`: recorded annual-return chart and full-run summary. The plotted source is [annual-returns.csv](../examples/pivot-spring/annual-returns.csv).
- `pivot-spring-mobile-light.svg` and `pivot-spring-mobile-dark.svg`: the recorded session summary for narrow screens.
- `social-preview.svg`: editable source for the 1280 × 640 repository social-preview image.
- `social-preview.png`: upload this PNG in GitHub's repository settings.

The README uses `<picture>` to select light or dark artwork. The text and tables around the images preserve the main message and results for readers using assistive technology or viewing the Markdown without images.
